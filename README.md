# Harel-RF-Filter-Board-
Development Board for testing various Elliptic Filters (9th Order). The PCB is designed as a 4-layer board JLCPCB 4-layer stack-up (non-RF specialized) in order to keep manufacturing costs low (for self home project ). with controlled 50 Ω impedance traces, ensuring accurate RF measurements and proper matching to standard 50 Ω test equipment
